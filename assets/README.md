# Static manuscript assets

`ceiling_fan.png` is the retained source image for manuscript Figure 3. No generating script or underlying experimental table was found in the project, so the figure runner copies it verbatim and does not claim to regenerate it.

The bitmap visibly plots "Probability of Acceptable" against "Air Speed (m/s)". The current manuscript caption instead describes fan speed versus measured air speed. The maintainer must resolve that content/caption mismatch before submission.

The manuscript attributes the fan-speed/air-speed relationship to Lei et al. (2023), “Experimental evaluation of thermal adaptation and transient thermal comfort in a tropical mixed-mode ventilation context,” *Building and Environment*.
